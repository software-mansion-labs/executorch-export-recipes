# Community duty guidelines 🫡

### Motivation

The purpose of this doc is to give you an idea on what you should do when being on a community duty for React Native ExecuTorch. Before, the task was treated pretty [**frivolously**](https://pl.bab.la/slownik/angielski-polski/frivolously), I am creating this doc in hopes that more *formal* definition of this task brings some more traffic into our repository.

***FEEL FREE TO EXPAND THIS LIST AND ADD YOUR OWN IDEAS!***

### Creative marketing work

This is a hard one, but I believe a community officer should invest some time in creating creative content for SM platforms (for example X). Take a couple of minutes to think if there is anything that you could do (a short demo, preview of a functionality that you’re working on, or some cool usage of our library) that is cool enough to be posted on X. It doesn’t need to be posted by Software Mansion, you can just do it from your own account. Here are some references:
